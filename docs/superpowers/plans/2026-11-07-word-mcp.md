# Word MCP for Windows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a stdio MCP server `word-mcp` that reads and controls a running Microsoft Word over COM, with curated tools plus a gateway reaching the whole object model.

**Architecture:** A shared `office_mcp.core` package owns COM threading (one STA worker thread), connection/reconnect, error mapping, serialization, the COM-path gateway and safety rules. `office_mcp.word` holds tool modules. Each tool module contains plain sync functions `fn(app, ...)` (testable directly against an isolated Word) plus a `register(server, run)` that exposes them as async MCP tools executed on the COM worker.

**Tech Stack:** Python 3.11, uv, `mcp>=2.3,<3` (`MCPServer` API — FastMCP was renamed in 2.x), `pywin32>=306`, pytest.

**Spec:** `docs/superpowers/specs/2026-11-07-word-mcp-design.md`

## Global Constraints

- Python `>=3.11`; deps exactly `mcp>=2.3,<3`, `pywin32>=306`; dev: `pytest>=8`.
- MCP API: `from mcp.server.mcpserver import MCPServer`, `from mcp.server.mcpserver.exceptions import ToolError`, `from mcp.types import ToolAnnotations` (snake_case hints: `read_only_hint`, `destructive_hint`, `idempotent_hint`, `open_world_hint`). Reference: `D:\AutoCad-MCP\src\autocad_mcp\server.py`. (Spec §3 says "FastMCP app" — read it as `MCPServer`.)
- Logging to stderr only; stdout is the MCP channel.
- Every tool name starts with `word_`. Entry point script `word-mcp = "office_mcp.word.server:main"`.
- Late binding only (`win32com.client.dynamic.Dispatch` / `GetActiveObject` / `DispatchEx`); never `gencache.EnsureDispatch`.
- No COM object ever leaves the worker thread; tools return JSON-safe values via `to_jsonable`.
- Errors surface as `ToolError("[CODE] message — hint")`; codes exactly: `WORD_NOT_AVAILABLE, WORD_BUSY, DOC_NOT_FOUND, RANGE_INVALID, COM_ERROR, BLOCKED, VBA_DISABLED, VBA_NOT_TRUSTED, UNSAVED_CHANGES, FILE_EXISTS, TIMEOUT`.
- Env vars: `WORD_MCP_ALLOW_VBA` (default `0`), `WORD_MCP_UNSAFE_GATEWAY` (`0`), `WORD_MCP_CALL_TIMEOUT` (`60` s), `WORD_MCP_BUSY_RETRY` (`10` s).
- Gateway blocklist (case-insensitive, any segment): `Quit, Kill, Shell, SendKeys, VBProject, VBE, MacroContainer, OrganizerDelete`.
- No overwrite by default (`save_as`, `export_pdf`); `close` refuses unsaved changes unless `save` or `force`.
- Units: all lengths in points; colors as `"#RRGGBB"` (converted to Word's BGR int). File paths must be absolute.
- Integration tests use `@pytest.mark.word` and an isolated Word via `DispatchEx`; they never touch the user's open documents.

## Review Focus

1. **Vietnamese / Unicode text** (e.g. `"Tiếng Việt có dấu ✓"`) must round-trip exactly through insert → read → find_replace. Test in Task 6.
2. **Paragraph indices after edits**: replacing paragraph N's text must not merge it with N+1 (the trailing ¶ is preserved) and paragraph count stays the same. Test in Task 6.
3. **Relative or missing file paths** in open/save_as/export_pdf/insert_picture/mail_merge must fail before reaching Word with `[RANGE_INVALID] Path must be absolute: <p>` (helper `require_absolute`), and a missing input file with `[RANGE_INVALID] File not found: <p>` — never an opaque `COM_ERROR`. Tests in Task 4 (save_as) and Task 9 (insert_picture).
4. **Word busy / modal dialog** must yield `WORD_BUSY` within `busy_retry` seconds, never hang; a job exceeding `call_timeout` yields `TIMEOUT`. Test in Task 3.
5. **Large documents**: `read_text` with `max_chars` must truncate on a paragraph boundary and return `next_paragraph` that continues exactly where it stopped. Test in Task 5.

Tool module contract (all of Task 4–14):
```python
def some_tool(app, *, document: str | None = None, ...) -> dict | list: ...   # sync, runs on COM thread
def register(server: MCPServer, run: Runner) -> None: ...                     # wraps each fn as async tool
```
`register` defines `@server.tool(name="word_x", annotations=READ|WRITE|DESTRUCTIVE)` async functions whose body is `return await run(some_tool, **params)`. Annotation constants `READ, WRITE, DESTRUCTIVE` live in `word/runtime.py`.

### Task 2: Gateway path parser + safety

**Files:**

**Interfaces:**
- Produces:
  - `@dataclass(frozen=True) class Segment: name: str; args: tuple[Any, ...] | None` (`None` = no parentheses; `()` = empty call).
  - `@dataclass(frozen=True) class ComPath: segments: tuple[Segment, ...]` (first segment is the root).
  - `parse_path(text: str) -> ComPath`; raises `OfficeMcpError("RANGE_INVALID", ...)` on syntax error, message includes the character offset.
  - `ROOTS = {"Application", "ActiveDocument", "Selection", "Documents"}`; a path whose first segment is not in `ROOTS` is treated as relative to `Application` (prepend `Segment("Application", None)`).
  - `check_path(path: ComPath, settings: Settings) -> None` raises `OfficeMcpError("BLOCKED", "Member 'X' is blocked", hint="set WORD_MCP_UNSAFE_GATEWAY=1 to allow")` unless `settings.unsafe_gateway`.

Grammar (hand-written tokenizer; args parsed with `json.loads` per comma-separated token, respecting quoted strings and nested parentheses are NOT allowed inside args):
```
path    := segment ('.' segment)*
segment := IDENT ('(' [arg (',' arg)*] ')')?
IDENT   := [A-Za-z_][A-Za-z0-9_]*
arg     := JSON number | JSON string (double quotes, escapes) | true | false | null
```

### Task 3: COM worker thread, busy retry, connection

**Files:**
- Create: `src/office_mcp/core/com_thread.py`, `src/office_mcp/core/connection.py`, `tests/conftest.py`
- Test: `tests/unit/test_com_thread.py`, `tests/integration/test_connection.py`

**Interfaces:**
- Consumes: `OfficeMcpError`, `RPC_E_*`, `Settings` (Task 1).
- Produces:
  - `call_with_retry(fn: Callable[[], T], busy_retry: float, sleep: Callable[[float], None] = time.sleep) -> T` — retries while `pywintypes.com_error.hresult` is a busy HRESULT, back-off 0.1 s doubling to max 1 s, until `busy_retry` seconds elapsed, then raises `OfficeMcpError("WORD_BUSY", "Word is busy or showing a dialog", hint="Close any open dialog in Word and retry")`.
  - `class ComWorker`: `__init__(name: str = "com")`; `start() -> None` (thread runs `pythoncom.CoInitialize()` once, loops on `queue.Queue`); `async run(fn: Callable[[], T], timeout: float) -> T` (submits, awaits via `asyncio.wrap_future`, on timeout raises `OfficeMcpError("TIMEOUT", f"Word did not respond within {timeout:g}s")`); `stop() -> None`. Message-filter registration is NOT required; `call_with_retry` is the retry mechanism (spec §3.1 fallback chosen for determinism).
  - `class AppConnection`: `__init__(progid: str = "Word.Application", visible: bool = True)`; `get() -> CDispatch` (must be called on worker thread; cached; liveness check `app.Name`; on failure reconnects once; attach via `GetActiveObject`, else `DispatchEx` + `Visible=True`; if both fail → `OfficeMcpError("WORD_NOT_AVAILABLE", ..., hint="Is Microsoft Word installed?")`).
  - `@contextmanager alerts_suppressed(app) -> Iterator[None]` — saves `app.DisplayAlerts`, sets `0`, restores in `finally`.
  - `tests/conftest.py`: session fixture `word_app` (`pythoncom.CoInitialize()`, `DispatchEx("Word.Application")`, `Visible=False`, `DisplayAlerts=0`; teardown closes all docs without saving + `Quit()`); function fixture `doc` (`word_app.Documents.Add()`, teardown `Close(0)`); skip all `word`-marked tests if `DispatchEx` raises.
